## はてなブログをやめて、個人サイトに移った
いままで個人ブログとしては、はてなブログの有料プランをつかってきたのですが、最近は技術系の記事はzennに書くことあり、記事の二重管理が続いていました。
また、有料プランのメリットも薄れてきたので、はてなブログではなく、個人サイトに移行することに決めました。

以前から、個人の箱庭的なサイトはほしいなとおもっていたのですが、なかなか腰があがりませんでした。
が、世はvibe coding時代、この機会に個人サイトを作ることにしました。

とはいえ、個人サイトを作成したところで、zennとの二重管理は続きます。
そこで、zennと個人サイトの同時配信を要件として開発を行い、
できたのが、[koylog.com](https://koylog.com/) です。
zennに投稿した記事 + 雑記などの個人記事を一つの場所に同居させています。

## どうやるか？
zennにはすでに、githubを使って記事を管理する仕組みがあります。
その仕組にのっとり、記事の管理をgithubに一本化し、zennと個人サイトの両方に配信することにしました。


```
              ┌→ zenn.dev     (articles/ のみ)
1つのリポジトリ ─┤
              └→ koylog.com   (articles/ + posts/)
```

- `articles/` … Zennにも出す技術記事
- `posts/` … 自サイトだけに出す記事（はてなから移したもの等）

### 実装について
フロントエンドは、[Astro](https://astro.build/) をつかって作成し、ホスティングは、[Cloudflare Workers](https://workers.cloudflare.com/) をつかっています。
独自ドメインもCloudflareで取得してます。

Zennが見にいくのは `articles/` だけなので、その隣に `posts/` を置けば、後者は自動的に自サイト限定の記事になります。
また、`title` / `emoji` / `type` / `topics` / `published` など、記事のfrontmatterはZennのものをそのまま流用しているので、
結果として、書くときの手順はZennも個人サイトも変わらず記事を作って `git push` すれば、両方が更新されます。

さらに、`:::message` のような独自記法も、Zenn自身が記事の表示に使っているパッケージをそのまま借りているので、
記事に見た目デザインは気にせずに書くことができます。

### コストについて
ホスティングは無料なので、ランニングコストはドメイン代（年間 2,000円ぐらい）だけです。
